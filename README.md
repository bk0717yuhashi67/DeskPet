# 桌面企鹅 DeskPet Penguin

一只住在桌面上的卡通企鹅。会自己动、会陪你工作、会跟你抛球、会在该吃饭和该睡觉的时候提醒你，
也会根据你今天的电脑使用状态，决定要不要开口说话。

纯本地运行，**不联网**，所有数据只存在你自己的电脑上。

![风格](https://img.shields.io/badge/风格-卡通平面-1B2A4A) ![依赖](https://img.shields.io/badge/Python-3.11%2B-2B6FE0) ![界面](https://img.shields.io/badge/UI-PySide6-D8342E)

## 〇、它长什么样

一只**头全黑、矮胖圆滚滚**的傻企鹅。

- **头和身体是同一个黑色轮廓**。不是"一个圆球脑袋 + 一个身体"，而是两个椭圆
  取并集（`rig.silhouette_path`），所以看不出接缝；头部动画直接作用在头椭圆上，
  头摆动时轮廓始终连续。
- **眼睛 = 白色眼白 + 两个小黑点**。闭眼时黑点变成一道朝上拱的弯钩
  （眼白保留，否则黑眼钩在黑脑袋上根本看不见）。
- **喙只有一层**宽三角。张嘴就是把同一个三角形整体拉长，没有第二层，
  结构上不可能出现"两层错位露缝"。
- **有脖子**。头椭圆（43 宽）比身体椭圆（56 宽）窄，两者交界处只有约 30，
  于是并集轮廓在 y≈104 处天然收腰——围脖就是系在那里的。
  没有这段收腰，围脖看上去只是"贴在肚子上的一条红带子"。
- 高宽比 1.19（改造前 1.79），比原来矮胖得多。造型这几条都有测试盯着：
  `interactive_test.py` 的「新造型」用例直接数渲染像素（额头必须全黑、
  张嘴后橙色区域必须连成一块、轮廓高宽比上限）。

## 一、快速开始

**日常启动（三选一，效果一样）：**

```
双击「桌面企鹅」快捷方式     ← 最省事：无黑框、图标是企鹅
双击 启动企鹅.lnk            ← 同上，放在项目目录里
双击 start.bat              ← 最稳：万一上面两个都没反应就用它
```

三个入口最终都会调用 `launch.py`，它负责建环境、装依赖、启动，并在**失败时弹窗告诉你原因**。

第一次用建议直接双击 `start.bat`：它会自动建虚拟环境并安装依赖（约 80MB），
过程中能看到进度；以后再双击任意一个都可以。

> 托盘右键菜单里也有「创建桌面快捷方式」，不小心删了随时能补。

**注意**：如果双击 `start.vbs` 没反应，通常不是程序的问题，而是系统的
**Windows Script Host 被安全软件关掉了**。这种情况用 `start.bat` 或快捷方式即可。

**网络不好装不上依赖？** 用离线方式：

```bash
python tools\offline_install.py download   # 带断点续传把 wheel 抓到 wheels/
python tools\offline_install.py install    # 从本地目录离线安装
```

启动后企鹅会出现在桌面右下角。**所有操作都在托盘图标的右键菜单里**（托盘图标就是企鹅的头像）。

### 启动失败怎么办

`launch.py` 会把每次启动写进 `data\logs\launch.log`；如果主程序启动后立刻退出，
它会把真实报错抓出来弹窗，同时也留在 `data\logs\launch_stderr.log`。
所以不会再出现"双击了但什么都没发生"的情况。

## 二、功能

### 1. 定时动作 + 点击互动

企鹅待机时会自己呼吸、眨眼、瞳孔跟着你的鼠标转。鼠标靠近到 160px 以内，它会把头转过来看你；
再近一点会好奇地歪头。

**主动动作刻意做得很少**：每 45–120 秒才可能抽一个小动作，每小时最多 3 次
（安静型默认；可在设置里调）。动作库里有 20 多个：张望、扇翅膀、跳一下、转个圈、伸懒腰、
打哈欠、摇摆走、无聊发呆……

**点击**：点它肚子会"被戳到"——软骨一弹、腮红上来、眼睛眯成一条缝。
连着点几次它会开始吐槽（"别戳啦，痒"）。

**拖动**：按住拖走，它会挣扎（蹬腿、乱扇翅膀、瞪大眼睛）；松手后吸附到最近的屏幕可用区域内。

托盘菜单「立即做点什么」可以手动让它挥手 / 转圈 / 跳一下 / 伸懒腰 / 打哈欠 / 点点头 / 扇翅膀 / 委屈一下。

### 2. 抛球小游戏

托盘右键 →「开始抛球小游戏」。

- 企鹅先扔一球过来
- **把鼠标移上去，碰到球就算扔回去**（不用点；鼠标停着不动、球自己滚过来也算）
- 企鹅接住并扔向场地的另一处——**故意不扔到你鼠标底下**，否则变成自动来回打
- 循环。三次失误结束（**球一停下就只剩 1.5 秒**没人碰，就算漏掉一颗心）

球是颗会自旋的沙滩皮球，有完整的抛物线物理（重力、空气阻尼、落地弹跳衰减、撞墙反弹），
地面上会画落点虚影帮你预判。到了该你出手的时候，球外面会套一圈会呼吸的虚线环。

难度每命中 5 次升一级（最高 6 级）：球变快、重力变大、三级开始刮"风"、四级球变小、
五级落地会抖一下。连击 5/10/20 有额外庆祝。

计分是 `(10 + 2×连击) × 难度系数 × 出手时机加成` —— 趁球还在滚就追上去碰，比等它停稳得分高。
结算会显示得分、最高连击、命中率、用时和历史纪录（新纪录企鹅会撒星星）。

### 3. 提醒闹钟

托盘右键 →「提醒设置」。

内置三条，可以直接改、停用或删除：

| 时间 | 内容 | 企鹅动作 |
|---|---|---|
| 12:00 | 该吃饭啦～好好吃一顿，别对着屏幕扒饭哦 | 低头吃饭 |
| 18:00 | 六点了，该吃饭啦！今天辛苦了 | 低头吃饭 |
| 22:00 | 该休息了，早点睡，明天再战～ | 打哈欠 + 问你睡不睡 |

另外可以自己加任意多条：每天 / 每周指定星期几 / 只提醒一次，自选时间、文案、企鹅动作、
是否带提示音、是否"紧急"（能穿透安静模式）。

**到点时的表现**：企鹅做对应动作 + 头顶弹一个带「稍后」「知道啦」按钮的聊天气泡 + 可选提示音。
22:00 那条会自动附上今天的使用小结。

**错过补偿**：电脑关机或睡了一觉之后重新打开，落在宽限期内的提醒会补一次
（饭点 90 分钟、休息 60 分钟、自定义 30 分钟），文案会变成"刚才 12:00 是饭点，补一句"；
超出宽限期的就不打扰了，只在你下次说话时轻描淡写提一句"今天错过了 2 个提醒哦"。

### 4. 电脑使用数据与状态分析

托盘右键 →「数据面板」。这是这只企鹅跟别的桌宠最不一样的地方——它会**看你状态**。

**采集什么**（全部只存本地，详见第五节隐私说明）：

| 类别 | 具体项 |
|---|---|
| 时间 | 今日活跃时长、各应用前台时长、空闲时长、锁屏时长 |
| 输入 | 按键次数、退格次数、鼠标点击次数、鼠标移动距离 |
| 行为 | 应用切换次数、连续专注时长、专注块数量、深夜活跃分钟数 |

**怎么分析**——所有指标都是明确的公式，不是玄学：

| 指标 | 公式（简化） | 用途 |
|---|---|---|
| **退格率** | `退格 ÷ 总按键` | >25% 说明你在反复改同一段东西 |
| **切换率** | `切换次数 ÷ 活跃小时` | >40 次/小时说明窗口开得很乱 |
| **专注度** | `50%×最长专注块 + 30%×少切换 + 20%×少退格` | 45 分钟专注块算满分 |
| **活跃度** | 每分钟输入密度（按键 + 1.5×点击 + 鼠标距离/60） | 区分"在阅读"和"在猛敲" |
| **疲劳度** | `30%×用机时长 + 25%×连轴时长 + 25%×深夜时长 + 20%×空闲碎片化` | 与昨天做指数平滑，避免单日噪声 |
| **熬夜指数** | 23:00–05:00 的活跃分钟数，4 小时封顶 | 滚动三天加权，连续熬夜会升级措辞 |
| **心流强度** | 连打长度中位数 + 粗算速度 + 低退格率 | >0.7 判定"心流中" |
| **分心指数** | 切换率 + 缺少长专注块 | |

**这些指标会变成企鹅的态度**：

| 企鹅看到的状态 | 触发条件 | 它会怎么做 |
|---|---|---|
| 熬夜关切 | 熬夜指数 >70 或凌晨 1 点后还在用 | 头顶冒 "!"、眼神担忧、说"已经这么晚啦…明天还要早起吗？" |
| 疲劳关切 | 疲劳度 >75 | 打哈欠、动作整体放慢到 0.8 倍速，"你连着好几个小时了，站起来走两步吧" |
| **专注陪伴** | 专注度 >70 且心流 >0.6 | **完全静音，只保留呼吸**——"我陪着你，但不打扰你" |
| 有点卡住 | 退格率 >25% 且你在高强度输入 | 皱眉歪头，"改了好多遍呀，要不要先喝口水再想？" |
| 有点分心 | 分心指数 >65 | 频繁左右张望，"今天开了好多窗口呢，要不要挑一件先做完？" |
| 状态不错 | 专注度 >75 | 坐姿端正、翅膀收好，"状态不错，我陪着你" |
| 干劲十足 | 活跃度高且不累 | 随机跳一跳、撒欢，"今天敲得真带劲！" |

心情切换有 5 分钟滞回确认，不会在临界值上反复横跳。心流状态下随机动作频率直接降到 0。

**如果这些数据还不够，还能补充统计什么？** 数据面板底部列了完整清单，包括：
空闲碎片化分布（区分"深度工作"和"每两分钟被打断一次"）、全屏（视频/游戏）时长、
正在编译或下载时自动静默、音频占用（在听歌还是开会）、按键类型粗分类
（方向键多=写代码、纯字母=写作，同样不含内容）、每日首次输入时间（推断起床作息）、
连续使用天数、7 日打字速度趋势、专注中被打断的次数。

### 5. 关怀小功能

所有主动行为都受一个"打扰预算"约束：**每天最多 8 条主动消息、两条之间至少隔 8 分钟**，
并且在这些情况下自动闭嘴——全屏程序、会议、游戏中、睡眠时段、心流中、
以及你正处在心流里、电脑正在编译/下载/渲染时。

按性价比排下来最值得的几个：

1. **作息守护** —— 23:30–07:00 自动趴下打呼（Z 字往上飘），几乎零动作零气泡。
   检测到全屏或会议进程自动静默。一个开关覆盖"夜间 + 会议 + 游戏"三种场景。
   不打扰，就是最好的关怀。
2. **眼神跟随** —— 瞳孔实时追你的光标，靠近会转头看你。几十行代码换来"这东西是活的"的感觉。
3. **健康提醒包** —— 连续活跃 50 分钟提醒起身（企鹅陪你做操）；每 45 分钟屏幕时间提醒远眺
   （20-20-20 法则）；每 75 分钟提醒喝水。共用一个预算，一句话 + 一个动作，没有弹窗。
4. **专注陪伴** —— 见上一节的"专注陪伴"状态。用"变安静"作为正向反馈。
5. **离开 / 回来问候** —— 空闲超过 15 分钟后回来，企鹅小跑着迎上来"你回来啦！"，
   并把期间错过的提醒一次性摘要播报。

其余的：熬夜渐进关切（>50 打哈欠，>70 严肃措辞，连续三天会播一段带具体数据的"郑重关切"）、
每日陪伴天数与 7/30/100 天里程碑徽章、22:00 当日使用小结、25 分钟番茄钟
（右键启动，企鹅戴上围脖进入不打扰状态）、早晚问候、久未互动时企鹅自己玩球/整理围脖/数羽毛、
以及自定义待办和吃药提醒（复用提醒系统）。

## 四、设置项

「设置」里有六组：

- **外观** —— 企鹅大小（75% / 100% / 135%）、点击穿透方式
- **提醒** —— 打开提醒设置（增删改吃饭/喝水/休息这类定时提醒，可试听一次）
- **打扰强度** —— 主动消息上限（默认 8 条/天）、两次间隔（默认 8 分钟）、随机小动作上限（默认 3 次/小时）
- **作息** —— 夜间自动睡觉开关、入睡与起床时间、空闲多久入睡
- **隐私与数据** —— 是否统计键鼠、是否记录窗口标题、**暂停统计**、打开数据目录、**清除今日数据**、清空全部数据
- **提示音** —— 开关与音量（默认 30%）
- **系统** —— 开机自启（写当前用户的启动项，不需要管理员权限）

## 四·五、统计数据是怎么变成企鹅的态度的

这是这只企鹅和普通桌宠最大的区别：**八项指标算出来之后，真的会改变它说什么、做什么。**

`pet/mood.py` 把指标映射成 9 种心情（带 2 次确认的滞回，防止临界反复横跳），
`care/features.py` 的 `MOOD_VOICE` 再把每种心情映射成**专属台词场景 + 专属动作**：

| 心情（触发条件） | 说话场景 | 配套动作 | 动作频率倍率 |
|---|---|---|---|
| 熬夜关切（熬夜指数>70 或凌晨） | `care_stayup` / `care_stayup_hard` | 难过 | ×0.4，眼神下垂 |
| 疲劳关切（疲劳度>75） | `care_tired` | **打哈欠** | ×0.35，动作放慢到 0.8 |
| 专注陪伴（专注>70 且心流>0.6） | `focus_start` / `focus_end` | 不说话 | **×0**，一句不吭 |
| 有点卡住（退格率>25%） | `frustrated` | 难过 | ×0.6，眯眼 |
| 有点分心（分心指数>65） | `distracted` | **东张西望** | ×0.8 |
| 状态不错（专注>75） | `focused` | **点头** | ×0.5 |
| 干劲十足（活跃>60 且疲劳低） | `cheerful` | **庆祝** | ×1.4，脸红 |
| 有点困（长时间没动静） | `sleepy` | 连眨两下 | ×0.3，眼睛半闭 |
| 平静 | 不说话 | — | ×1.0 |

除了心情，还有几条纯由数据/时钟触发的：

- **心流进入/离开**各说一句，中间完全沉默（这是核心设计：陪着但不打扰）
- **机器忙完**（CPU 高占用结束后）补一句"刚才你忙得正紧，我没吵你"
- **饭点过了一小时人还在敲键盘** → 提醒去吃饭（每天一次）
- **饭点漏提醒**（关机/休眠错过）→ 重启后补一句
- **安静了 4 分钟** → 自言自语一句
- **久坐 / 护眼 / 喝水** 三个健康计时器
- **陪伴天数里程碑**（7/30/100/365 天）

所有这些都要过打扰预算：**每天 ≤8 条、间隔 ≥8 分钟**，而且全屏/会议/游戏/睡眠/
心流/编译中一律闭嘴。台词库共 45 个场景、每场景 3~4 条随机，另有测试专门盯着
"每种心情的台词场景和动作必须互不相同"（见 `interactive_test.py` 的「指标驱动发言与动作的区分度」）。

## 五、隐私

这是设计时排第一位的约束：

1. **不联网**。代码里没有任何网络请求，没有 `requests`、没有 `socket`、没有上传逻辑。
   唯一的网络行为是安装依赖时下载 wheel。
2. **键盘只记录次数和间隔**，不记录任何字符内容——连按了哪个键都不取，只数"按了一下"和
   "按了退格"。不截图，不读剪贴板，不碰密码框。
3. **数据位置可见可删**：`data\pet.db`（SQLite）。设置面板里有「打开数据目录」按钮。
   「暂停统计」随时能停。「清空全部数据」会真的删掉并回收文件空间。
4. **首次运行会弹一个说明弹窗**，你可以选择「仅用基础功能（不采集输入）」——
   那样企鹅只统计应用时长和空闲，不碰键盘鼠标。
5. **窗口标题可以关掉**。关掉之后浏览器里的活动只能归到"浏览器-未分类"，
   分类精度会下降，但隐私更干净。
6. **不记录按键内容、不做行为画像、不向外传输任何数据。**

### 几个关键设计决定

- **点击穿透**：主方案是拦 `WM_NCHITTEST` 返回 `HTTRANSPARENT`，让点击落到下层窗口。
  启动时会做一次自检（发两条消息验证"轮廓外穿透、轮廓内可点"，再用 `WindowFromPoint`
  交叉验证），**自检不通过会自动降级**为动态开关 `WS_EX_TRANSPARENT`。
  所以即使某个系统上主方案失效，也不会出现"点不到桌面"的事故。
  刻意没用 `setMask()`——它是二值区域会切掉抗锯齿边缘产生锯齿，而且每帧重建会很卡。
- **气泡用独立窗口**：气泡会超出企鹅画布，同窗绘制就得放大窗口并同步扩大命中排除逻辑，耦合太重。
- **游戏输入走全局钩子**：所以点屏幕任何地方都能抛球，不需要吃 Qt 事件，跟穿透逻辑零冲突。
- **动画是数据驱动的**：`rig.py` 只画几何、`clips.py` 只存关键帧、`animator.py` 只做插值。
  加一个新动作只需要往 `clips.py` 里加一条数据。
- **存储用 SQLite 而不是 JSON**：高频追加 + 按时间范围聚合 + 崩溃安全，JSON 每 30 秒重写整份文件
  会有写放大，崩溃还容易截断。

## 八、开发

三层验证，从便宜到贵：

```bash
# 1) 纯函数单测（35 项，毫秒级）：物理、指标公式、缓动、关键帧
.venv\Scripts\python.exe -m unittest discover -s tests -v

# 2) 装配链冒烟测试（18 项）：模块能否导入、对象能否构造、渲染能否出图、
#    数据库读写、采样器能否真的读到前台窗口
.venv\Scripts\python.exe tools\smoke_test.py
.venv\Scripts\python.exe tools\smoke_test.py --gui   # 额外显示窗口并验证点击穿透

# 3) 功能测试（9 项）：数据面板刷新、提醒增删改、气泡按钮、抛球小游戏跑完整一回合
.venv\Scripts\python.exe tools\interactive_test.py

# 4) 目视检查造型与游戏画面
.venv\Scripts\python.exe tools\preview_game.py   # 球 / 提示环 / HUD
.venv\Scripts\python.exe tools\shot_game.py      # 真开一局，真的动鼠标去打
.venv\Scripts\python.exe tools\preview_penguin.py --hit   # 生成 preview_penguin.png

# 5) 语法检查
python -m compileall -q app ui pet monitor game remind care tests main.py
```

两个容易踩的坑，都踩过了，这里记下来：

- **项目根目录不是包**，所以模块之间只能用绝对导入（`from app import ...`）。
  写 `from ..app import ...` 会在启动时直接崩——因为 `monitor` 这类顶层包没有父包可退。
- **Qt 会吞掉 `paintEvent` 里抛出的 Python 异常**（只在控制台打一行堆栈，程序照跑）。
  `tools/interactive_test.py` 里装了 `qInstallMessageHandler` 把它揪出来，
  否则绘制层出问题根本不会被发现。

另外还有几个更隐蔽的，属于"以后别再犯"：

- **`.bat` 里绝对不能出现非 ASCII 字符。** cmd.exe 用系统 OEM 代码页（中文 Windows 上是 GBK）
  解析 .bat，文件里的 UTF-8 中文字节会被错解，而且错解出来的多字节序列会**吃掉后面的引号、
  换行、`%`**，直接破坏脚本结构。症状是双击后刷一堆乱码错误，比如
  `'orlevel' 不是内部或外部命令`（本该是 `if errorlevel`）、`'ySide6' ...`（本该是 `import PySide6`）。
  所以 `start.bat` / `start.vbs` 一律纯 ASCII，中文全部交给 `launch.py` 用 `MessageBoxW` 显示。
- **`IShellLinkW` 的虚表下标不是字母序**，而是"get/set 成对、功能分组"：
  `GetPath 3, GetIDList 4, SetIDList 5, GetDescription 6, SetDescription 7,
   GetWorkingDirectory 8, SetWorkingDirectory 9, GetArguments 10, SetArguments 11,
   GetHotkey 12, SetHotkey 13, GetShowCmd 14, SetShowCmd 15,
   GetIconLocation 16, SetIconLocation 17, SetRelativePath 18, Resolve 19, SetPath 20`。
  排错的话调用会"成功"但内容全乱（比如 SetPath 打到 SetIconLocation 上，
  目标就变成了解释器路径），而且不报错。所以 `app/shortcut.py` 里既写了详细注释，
  测试里也做了"扫字节 + COM 读回"双向校验。
- **`IShellLinkW::GetPath` 是 4 个参数**（多一个 `WIN32_FIND_DATAW*` 和 `fFlags`）。
  少传参数会让被调方从栈上读到垃圾指针，直接 access violation。
- **`QAction.triggered` 在 PySide6 里会解析成无参重载**。
  对可勾选菜单项写 `triggered.connect(sig.emit)`（sig 带 bool）会抛
  `TypeError: xxx(bool) needs 1 argument(s), 0 given`，表现是"点了菜单没反应"。
  正确写法：`triggered.connect(lambda _=False, a=act: sig.emit(a.isChecked()))`。
- **`.vbs` 依赖 Windows Script Host**，安全软件经常把它关掉。
  所以主入口应该是快捷方式或 `start.bat`，`.vbs` 只作为可选项。

主要依赖：Python 3.11+、PySide6-Essentials、pynput、psutil。

## 九、常见问题

**装依赖时一直失败（`IncompleteRead` / 连接中断）？**
PySide6 的 wheel 有 73MB，在部分网络下 pip 会中途断流。
用 `python tools\offline_install.py`：它带断点续传和 sha256 校验，
下完后用 `--no-index` 从本地目录离线安装，全程不再依赖网络稳定性。
另外**不要装 `PySide6` 元包**——它会连带拉 150MB+ 的 `PySide6-Addons`（QtWebEngine/Qt3D 等），
本项目只用 QtCore/QtGui/QtWidgets/QtNetwork，`PySide6-Essentials` 就够了。

**点不到企鹅，或者点桌面被挡住了？**
设置 → 外观 → 点击穿透，换成另一种方式（重启生效）。默认是"自动"：
启动时自检决定用 `WM_NCHITTEST` 还是降级到扩展样式。

**打字统计好像不准？**
Windows 的权限限制（UIPI）：普通权限的低级键盘钩子收不到以管理员身份运行的程序的输入。
程序会自动检测这种情况，并在数据面板里明确告诉你"统计可能不完整"，不会假装精确。
想完整统计就让企鹅也以管理员身份运行——但这是可选的。

**企鹅在游戏里看不见？**
独占全屏程序会盖住所有置顶窗口，这时企鹅会主动躲起来（顺便也是最好的不打扰）。
退出全屏自动回来。

**应用分类不准？**
浏览器里的活动靠窗口标题判断。可以在设置里开启窗口标题记录提高精度，
或者在 `data/config.json` 的 `app_category_override` 里手动指定，例如：
```json
{ "app_category_override": { "notion": "工作" } }
```

**企鹅太吵 / 太安静？**
设置 → 打扰强度（调低每日上限和随机动作频率）。全屏、会议、心流、编译中、
夜间睡眠时段它会自动闭嘴，不需要手动开关。

**想彻底重来？**
设置 → 隐私与数据 → 清空全部数据；或者直接删掉 `data\` 目录。
